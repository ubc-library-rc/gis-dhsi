# Reference Mapping

As a reminder, **reference maps** show the lay of the land, such as the geographic context surrounding your research location or area of interest. Reference maps can be as simple as a drop pin location, or more complex with data layers, labelling, and insets. Reference mapping, while not (necessarily) involving spatial analysis, still requires skill for the final map to look neat and polished. Like any map, reference maps should have at minimum an explanatory title, north arrow, scale, legend, map author and data source statement. If there are only one or two data layers which are intuitively symbolized and clearly marked, a legend is sometimes unnecessary.


In what follows you will be guided in gathering data, adding it to a QGIS project and managing layers, and finally, creating a map for export.
